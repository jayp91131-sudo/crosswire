## Database Creation and Cleanup Instructions
The prototype test suites execute against isolated in-memory databases (`:memory:`) or fresh temporary databases. 

To clean up physical database files generated by migration tests:
```powershell
Remove-Item -Path "disposable_*.db*" -ErrorAction SilentlyContinue
```
Running `run_migration_prototype.py` or `reproduce_clean_migration.py` recreates disposable databases cleanly from scratch at any time.
